# ANTITHESIS — The Demolition of AI Pretense

> **A razor-sharp, iconoclastic editorial landing page built with [taste-skill](https://github.com/leonxlnx/taste-skill).**
> Categorically refusing the sanctimonious 'Claude' aesthetic, faux-monastic literary posturing, and generic AI templates.

---

## 🏛️ Design Foundations

- **Direction**: `editorial-report` (The Printed Annual)
- **Palette**: Paper Ground (`#FAF8F5`), Sumi Ink (`#1D1B18`), Terracotta Accent (`#B34629`), and Inverted Dark Field
- **Typography**: 5-step strict scale with `Bodoni Moda` (Display) & `Jost` (Body)
- **Zero AI Slop Standards**:
  - ❌ No hairline borders or thin rules
  - ❌ No gradients, glows, or resting shadows
  - ❌ No pill badges ("NEW", "v2.0") or artificial counters (01, 02)
  - ❌ No glassmorphism or generic card grids
  - ✅ Masked line reveal signature headline
  - ✅ Pinned Interactive Workbench ("Iconoclastic Engine") with live real-time manuscript mutation
  - ✅ Open-access archival plates & historical printing press video loop

## ⚡ Deployment to Cloudflare Pages (Drop / Direct Upload)

This repository is **100% Zero-Build**: pure HTML5, CSS3, and modern Vanilla JS.

### Option A: Cloudflare Pages Direct Upload (Drop)
1. Go to [Cloudflare Dashboard](https://dash.cloudflare.com/) ➡️ **Workers & Pages**.
2. Click **Create application** ➡️ **Pages** ➡️ **Upload assets**.
3. Name your project (e.g. `antithesis-landing`), drag this repository folder directly into the drop zone, and click **Deploy Site**.

### Option B: Cloudflare Pages Git Integration
1. Connect your GitHub repository (`tonnychiulab/antithesis-landing`).

3. Build output directory: `.` (or root `/`)
